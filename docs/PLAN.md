## 3. 가정 (계약서에 없는 부분을 어떻게 해석했는가)
- 가정: M5 주문 조회와 expiry 도전 과제는 제공된 일정에 포함되지 않아 이번 계획 범위에서 제외한다.

## 4. 안전장치 (우리 팀이 지킬 것 3가지)
1. 한 번에 함수 하나 또는 수락 기준 하나만 작업하고, `docs/SRS_발췌.md`와 `docs/API_CONTRACT.md`를 대조한다.
2. 공개 테스트와 공통 도구 파일은 수정하지 않으며, 해당 미션 테스트 결과와 diff를 검증자가 확인한 뒤 수락한다.
3. 키·토큰·개인정보·카드번호를 코드, 테스트, 로그, 대화에 기록하지 않는다.
